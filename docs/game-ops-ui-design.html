01 / Design System

设计基线：不再像设置页，像一套战术装备

新语言以「深空底 + 发光边 + 切角面板 + 等宽数字」为骨架。所有界面共用同一套 token，游戏内控件只保留高频动作，复杂配置收进工作台。

07 / Icon System

统一图标套件：24px 网格 · 双色语义 · 游戏场景高辨识

同一套线宽、端点与切角规则贯穿功能、状态、导航三类图标。状态图标配专属语义色，导航图标使用低饱和灰，选中态用 Mint 高亮。

绘制规范：24×24 viewBox，1.8px 线宽，圆头圆角，外轮廓不超过 20×20 安全区；允许一处实心块作为「能量核心」，用于录制/执行/激活态。禁止拟物、渐变、emoji 与多色填充。
